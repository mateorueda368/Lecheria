# Regla del Proyecto: Revisión y Aprobación de Cambios

- **Aprobación Previa Obligatoria**: Antes de realizar modificaciones en el código fuente, archivos de configuración o esquemas de base de datos, el asistente debe presentar el plan detallado de cambios y esperar la confirmación explícita del usuario.
- **Transparencia**: Explicar qué archivos se van a modificar, qué lógica se agregará o cambiará y por qué es necesario.
